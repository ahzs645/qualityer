# Five-stage study analysis

The study interface connects source preparation, descriptive coding, interpretation, Framework comparison and researcher reflection. These activities can be revisited; moving to another stage does not mark analysis complete. Desktop shows the five-stage navigation; smaller screens use an expandable stage chooser. Links retain the project, current view and selected source across reloads.

1. **Prepare sources.** Speaker review keeps anonymous machine estimates separate from researcher-recorded labels. Source review presents source-linked wording tasks with exact quotations and playback before the associated source segment. Wording proposals stay unverified; a task decision alone does not correct a transcript. Consent and off-record scope decisions remain available separately. Stale or restricted task details are withheld.
2. **Code accounts.** Select a sentence, segment or exact Unicode character range. Six reading prompts cover experiences, actions, values, context, constraints and consequences; use only the prompts relevant to the passage. Apply descriptive codes and keep explanation or alternative readings in a linked memo. Transcript settings and precise navigation expand on demand so the text has room on mobile and desktop.
3. **Examine interpretations.** Evidence & interpretations separates descriptions, provisional explanations, qualifications and exact citations. Source and lens filters narrow the saved selections. Mobile uses a complete entry chooser rather than a long list above the selected account. Current evidence can be exported; the linked Framework chart retains its analytical collection.
4. **Compare accounts.** Framework rows represent source recordings until participant identities are established. Cells retain supporting and contrasting evidence, interpretation and qualifications. Current quotations are required; unsaved changes block recording review of an older interpretation. Counts describe selected evidence and work records, not prevalence, importance or saturation.
5. **Reflect & review.** Memos and the journal preserve reasoning and follow-up. Structured journals display method, scope, negative cases and review limits in readable sections; original content stays in the native project. Researcher review shows open wording tasks, anonymous voice estimates, unresolved segments and chart cells awaiting recorded review. Agent checks and researcher decisions retain their own attribution.

Browser validation uses both complete recordings in a separate local copy for reading, playback and cross-stage links. Writing, deferral, coding, passage memos and interpretation review are exercised on an entirely synthetic study. No browser exercise records review against the live interview project or certifies listening accuracy, identities or findings.

## Download the saved study

The owner can open **Export → Download all saved work** and choose a ZIP with recordings or a ZIP without recordings. Both include the current native project, exact transcript and timing companions, coding and review records, cases, memos, journals, Framework matrices, evidence-linked analysis, full retained recovery states, event history and retained processing-job results. The recording option includes every explicit current and historical media reference in the current project state.

Downloads stream from project storage so large recordings do not have to fit in the browser’s memory. Retained files have SHA-256 checksums in `EXPORT-SCOPE.json`; recovery copies are checked against their saved checksums. Export is read-only and restricted to the owner. A missing retained file blocks a complete archive rather than silently omitting work. Service credentials, private account notes, embedding caches and files never retained in project storage are excluded. Machine estimates and unresolved researcher reviews retain their recorded status.
