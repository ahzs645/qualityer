## Regression verification

`node --test tests/subcode-proposals.test.mjs tests/code-suggestions.test.mjs tests/ai-quality.test.mjs tests/research-services.test.mjs` passed **24 tests** after the added overlap regression. Tests cover exact Unicode evidence, immutable definition provenance, permissions, atomic validation, normalized sibling names, consent/source/code changes, invented citations, malformed or truncated model answers, existing-code overlap suppression, deleted/stale decisions, corpus paging, context budgets, cache changes and outlier methodology.

The adapter is verified using deterministic synthetic OpenAI-compatible responses. No live model endpoint was configured; no claim of real-model quality, desktop inference, or full upstream feature parity is made. Root integration and full app/browser checks are reported by the parent task.
