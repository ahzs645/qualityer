## Measurement contracts

Coverage is `union of eligible current coded codepoints / eligible source codepoints`. Duplicate and overlapping coding do not increase union coverage, but each saved coder application contributes to the separately labelled application rate. Code/coder/decision/quotation filters change the numerator. Source/case/source-attribute filters change the corpus denominator. Codepoint length is computed with `Array.from`, preserving emoji positions. Empty denominators yield N/A, never a fabricated zero.

Consent restrictions are removed from the denominator. A coding touching restricted text is withheld entirely rather than silently altering its quotation. Current case-passage membership can clip **measured** coverage; the original quoted decision remains available in drilldown. Invalid or stale restriction anchors fail closed for normalized coverage. Source revisions and exact quoted slices are checked before applications enter these views. Included consent decisions remain in source history and do not add active exclusion ranges; pending/withheld decisions do.

Heatmap overlap is `intersection / union` after separately merging each coder's intervals within each source and directly applied code. Codes retain distinct dimensions: coding the same positions to different codes creates no shared overlap. Empty unions yield N/A. Same-coder diagonals are one only when that identity has nonempty eligible coding. Scores describe current saved decisions and provide no evidence of independent coding, human consensus, saturation, representativeness, statistical significance or theme importance.

Relationship decomposition reconstructs exact current source slices only for overlapping eligible text pairs. There is no interpolation from transcript text to recording timestamps. Canonical stored coding wins over caller-supplied modifications. Exports distinguish codepoints from seconds and explicitly label the dependent application-pair unit.

## Verification

Focused checks in `tests/coverage-profile.test.mjs` and `tests/relation-evidence.test.mjs` cover overlap unions, parent/direct code measures, case passage clipping, restricted denominators, Unicode positions, invalid/stale/revision/removed/reference/media exclusions, typed source filters, heatmap symmetry and identity separation, equivalence with the existing pair-comparison formula for full-source scopes, CSV formula escaping, SVG/XML escaping, fractional recording bounds, canonical selection identities and omission of disjoint uncoded context.

The new tests and existing coder-comparison tests passed together: 20 checks. Separate actual-data verification matched all 24 source/code union totals against independently enumerated codepoint sets using the supplied exact machine drafts and Framework Method selections. Original interview files, generated reports and the verification script remain outside Git. These runs verify anchor/measurement behavior, not transcript accuracy or qualitative interpretation. Browser integration and the complete build/service suite are recorded in the task's final integration report; they are not asserted by these focused module checks.
