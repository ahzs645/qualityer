## Highest-value changes to implement now

1. **Paragraph-aware semantic retrieval with cache correctness.** Expose fixed versus paragraph/speaker-line chunking. Keep codepoint anchors exact; do not invent time bounds. Different chunk endings at the same source/start must re-embed rather than reuse stale vectors. Acceptance: emoji + CRLF + blank lines + long line + consent flags + reused revision restore + switching modes.
2. **Reject truncated model output, and disclose true provider context limits.** Reject `finish_reason=length` or `content_filter`, including valid JSON, before recording a complete draft. Apply in `chatJSON` and the separate suggestions route. Add explicit evidence sampling/context reserve next; no hardcoded assumption that32,000 text units fit every model.
3. **Adaptive outlier reading prompts.** Current lowest20% guarantees apparent outliers for every code. Use an explicitly described distribution threshold and minimum sample, allow no findings. Preserve current leave-one-out method rather than pretending it reproduces AQDA’s inclusive centroid. Acceptance:4 identical vectors→zero findings; one distinctive among4→one; fewer4→clear requirement; consent/exclusion/sample provenance preserved.

Smaller workflow opportunities after these: stable code/memo references, project archive/trash, filename attribute preview and bulk imports. More involved changes: whole-corpus example-seeded suggestions, native AQDA import, offline divergent draft comparison. A hosted web app should not copy desktop local-server controls that cannot function in that architecture.
