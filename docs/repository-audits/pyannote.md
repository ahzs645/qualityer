# pyannote.audio dedicated parity audit

Audited 2026-10-03. Upstream snapshot: `b749285c5cdd4636b2edc7f766f1352c8dde9369` in `/workspace/scratch/pyannote-audit`. Research Weave source checkpoint: `36853ffe4f238a85b94ef2a705f2d8aa69feb707`. This is source inspection plus local infrastructure/domain tests. **No pyannote/WhisperX inference, model download, GPU execution, Docker image build, or real audio speaker accuracy measurement was performed.** No private research records were used in acceptance checks.

pyannote.audio is a Python diarization component, not a qualitative-analysis workspace or transcription engine. Parity relevant to this app concerns speaker interval preservation, correction, uncertainty, audio synchronization, model service operation and provenance; reproducing its training/notebook framework in the web UI is not necessary.

## Ranked feasible fixes without model-service access

1. **Canonical diarization tracks and truthful overlap UI.** Preserve regular and exclusive interval arrays separately; nonnegative finite seconds, start < end, speaker IDs, source recording key, model run ID and scope. Render interval lanes and overlap flags over transcript/waveform. Keep original regular intervals unchanged when using exclusive assignment. Accept external synthetic imports; do not pretend the current adapter generated data it does not emit.
2. **Selected-turn speaker correction.** Add operation to reassign explicit stable turn IDs with rationale/status; retain raw model speaker, source version, actor/time and original intervals. First-class label merge/split should be source/run scoped. Presentation applies human corrections while raw words remain untouched. Restrict operation permissions consistently with transcript review.
3. **Reproducible job options and disclosure.** Exact/ranged speaker count validation, explicit diarization model selection and revision fields, telemetry disabled default, package version/config/source checksum capture, engine destination and model-condition state. Make health response disclose capabilities rather than implying all configured workers support global diarization.
4. **RTTM import/export and diarization JSON.** Preserve regular track, independently export exclusive track, include units/recording provenance and lossy-format notice. Use round-trip synthetic tests and reject malformed rows.
5. **Stage progress and actionable failure messages.** Report decode/transcribe/align/diarize/review stage with actual supplied progress; unknown stage progress remains indeterminate. Distinguish token/terms/configuration failure from transient infrastructure failure so permanent model-access errors do not consume pointless retry budgets.
6. **Global diarization protocol, not fake global inference.** Advertise `whole_recording_diarization` capability and reject unsupported multi-part requests before expensive transcription. Build result contract and synthetic cross-chunk tests now; enable global speaker clustering only after an approved worker can actually execute and measure it.

## Acceptance tests for proposed implementation

- Import synthetic regular tracks A:[0,2], B:[1,3] and exclusive A:[0,1.5], B:[1.5,3]. Preserve overlap [1,2] in regular output, display both lanes, and label exclusive view accurately. Export/reimport with identical precision, IDs and recording key. Reject negative/reversed/nonfinite intervals; preserve real zero.
- Reassign one turn out of two sharing SPEAKER_00; other turn remains unchanged. Raw speaker/words/intervals remain unchanged, correction history stores actor/rationale/date, source snapshot restores prior state, and export/import reproduces both raw and displayed assignments. Synthetic names only.
- Merge two displayed labels then split one selected turn. Corrections in source A do not change source B even if both use SPEAKER_00. Counts/filters/reading reports reflect corrected display identity consistently.
- Known speaker count must be positive integer; min <= max; exact count cannot silently coexist with conflicting range. Options survive API, durable queue restart, idempotency digest and result provenance. Changed options with same idempotency key produce conflict.
- A 1200-second boundary fixture with repeated local SPEAKER_00 labels must be rejected/marked chunk-local unless global identity evidence is explicitly provided. No synthetic assignment should claim actual global clustering was tested.
- Replacing attached recording preserves old model tracks and disables seeking against the new recording until explicitly checked/rebound. Old job completion must not silently attach to a different recording.
- RTTM synthetic round trip preserves speaker IDs, zero starts, fractional durations and overlapping intervals; malformed columns/NaN/negative duration fail with row-level errors.
- Result carries explicit ASR/align/diarization IDs, revisions when resolved, package versions, source checksum and processing destination. Unknown fields remain unknown rather than fabricated. Private worker config disables telemetry by default; actual network behavior tested when deployment is available.
- Later real-service gate: approved two-/three-speaker recording with deliberate overlap, long recording spanning transcription boundaries, human reference labels/intervals, measured diarization error and missed overlap, cancellation/restart recovery. No model accuracy or global identity claims before this gate.
