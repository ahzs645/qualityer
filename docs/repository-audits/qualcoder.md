## Three feasible fixes ranked

1. **Scoped IRaMuTeQ TXT + provenance JSON**: implemented as a public-safe scratch proposal at `qualcoder-proposal/iramuteq-export.mjs` plus three tests. Use current analysis filters and canonical selected applications, deduplicate identical exact excerpts across coder/code layers, group their metadata as binary presence indicators, omit media/invalid/restricted/reference ranges. Warn that nonidentical overlaps repeat words and this is not an interview-prevalence corpus. Parent integrated the module and report-builder TXT plus provenance-manifest downloads during this audit. Actual IRaMuTeQ import remains unverified.
2. **Modular ODT/plain-HTML text extraction with import preview**: two genuinely missing source formats can be added without introducing external providers. Strip active HTML and ODT annotations/hidden content according to explicit extraction rules; preserve original-format provenance and verify Unicode paragraph structure. RTF/EPUB/LaTeX follow as separately tested extractors.
3. **Waveform coded-range tracks and direct resize preview**: existing waveform is real; the improvement is per-code/coder packed range overlays and reviewed drag/keyboard resize. Bind recording identity, preserve zero/fractional times and attribute every edited range. For long recordings use downsampled server peaks rather than lifting local decode bounds.

Text+AV agreement extension is also useful but requires explicit unitization and union-area math; defer image-area kappa until rectangle geometry/denominator behavior is clearly tested.
