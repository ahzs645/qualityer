## Fixes exposed by the examples

- SQLite's normal browser text reader stripped a stored leading U+FEFF and truncated embedded NUL. Byte-preserving, typed projections now decode original UTF-8/UTF-16LE/UTF-16BE TEXT without changing stored characters. This recovered 83 valid RQDA anchors; it did not relocate any quotation. True BLOB, numeric and missing values retain their types.
- Native Requal uses its own schema and one-based inclusive segment bounds. It now has a separate allowlisted importer; historical IDs do not authenticate users or import permissions. Unknown versions, stale quotations and ambiguous relationships remain explicit review/provenance records.
- REFI descriptions, supplied source author/date metadata and AQDA's `creatingUserGUID` alias are preserved. Imported sources start excluded from AI. Standard QDPX exports retain Project Description; native snapshots retain all provenance.
- QualCoder passage cases no longer become whole-source links. Verified partial BMP ranges activate as passages; ambiguous non-BMP native Qt/Python bounds remain inert. Zero IDs, declared numeric/character attributes and missing values are retained correctly; stale quotations remain review records.
- Case CSV/XLSX previews explicitly map name, source and memo columns. Headers such as `case`, `Case` and `ID` need no manual spreadsheet rewriting. Other columns remain attributes; the app does not infer that an open answer is a transcript. CSV encoding is selectable, with strict UTF8/BOM decoding and legacy decoding only when chosen.
- QDC imports require a scoped CodeBook/Codes envelope; arbitrary XML containing a Code tag is rejected.
- ODT footnotes no longer concatenate into body prose. Omitted footnotes/endnotes are disclosed. DOCX core metadata, original-byte digest and conversion losses are retained.
- STM and transcript TSV imports are supported. Recognized document extensions take precedence over browser MIME guesses, including browsers labelling STM as tracker audio. WhisperX TSV units are milliseconds; our corrected transcript TSV declares seconds. Subtitle speaker labels come only from explicit `[speaker]:` markers. Missing timing and overlapping speakers remain supplied data. Speaker-track import is available for audio/video sources even before a transcript exists.

Original imported bytes are identified by SHA-256. Text conversion is distinct from lossless original-document storage; retain the source files separately. Each imported project's preview lists its preservation notes and uncertain anchors.

## Verification scope

The final private app passed 242 Node checks with zero failures/skips. The original private interview also passed its ten-workflow browser rehearsal again, with all 302 turns and 33 original coding records unchanged. The original private fixtures were not rewritten. No interview or public sample was sent to an external model.

Actual app file-picker tests use disposable local accounts and projects; standard exchange tests additionally exercise the actual Sift native core and previously verified QualCoder importer. Model execution, all native application UIs, every ancillary table and universal lossless exchange remain outside these results.
