# Completion verification

This pass integrates document conversion/local OCR, exact fragment/literal queries, reviewed autocoding, all-source AI context handling, concept maps/portraits/weighted hierarchy, case memos, native AQDA/Taguette/RQDA imports, portable codebook collections, safe memo references, structured decision changes, blind team permissions and canonical speaker tracks with a whole-recording diarization worker stage.

Verification is recorded after the final combined build. Model-contract fixtures are explicitly synthetic and do not establish model execution or accuracy. Browser rehearsals create disposable projects; original uploaded source fixtures are never rewritten. Public repository exports exclude private interview text, original archives, private history, account notes, credentials and prepared private-demo reports.

An actual private interview rehearsal checks every original turn and coding record, preserves exact source text/labels and missing timestamps, processes only consent-eligible ranges, and verifies source-linked results/native exports. Additional synthetic media fixtures exercise fractional/zero timing, recording replacement, overlapping speakers, rectangle unions and corrected subtitle/RTTM output. No audio boundaries are invented to populate the private transcript demo.

Actual upstream AQDA SQLite schema and Taguette ORM/highlight-extractor fixtures pass browser import; actual QualCoder PyQt QDC/QDPX importer passes current text/annotation/media/PDF exports. Whole-source case links lost by the upstream QualCoder SourceRef parser are disclosed. Full outward native snapshots and every external application's runtime roundtrip are not certified.

Language/embedding/transcription providers remain connection required. No private interview was sent to an external model during these checks. Whole-recording diarization has explicit duration/waveform gates; these are not total GPU/RAM guarantees. Infrastructure/offsite disaster recovery and formal accessibility/cross-browser certification are separate from tested project snapshots and Chromium interaction flows.
